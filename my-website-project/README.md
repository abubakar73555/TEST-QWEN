# My Website Project

مشروع موقع ويب بسيط باستخدام HTML و CSS و JavaScript.

## 📋 المتطلبات

- Node.js (v14 أو أحدث)
- npm

## 🚀 التثبيت

1. استنساخ المشروع:
```bash
git clone <repository-url>
cd my-website-project
```

2. تثبيت الاعتماديات:
```bash
npm install
```

## 📁 هيكل المشروع

```
my-website-project/
├── index.html      # الصفحة الرئيسية
├── style.css       # ملفات التنسيق
├── main.js         # كود JavaScript
└── package.json    # معلومات المشروع والاعتماديات
```

## 🎯 المميزات

- تصميم متجاوب
- واجهة مستخدم بسيطة وسهلة الاستخدام
- كود نظيف ومنظم

## 🛠️ التشغيل

افتح ملف `index.html` في المتصفح، أو استخدم خادم تطوير محلي.

## 📝 الترخيص

هذا المشروع مفتوح المصدر ومتاح للاستخدام الشخصي والتعليمي.
