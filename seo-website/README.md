# موقع SEO المتخصص مع لوحة التحكم

مشروع موقع إلكتروني متكامل يركز على تحسين محركات البحث (SEO) مع لوحة تحكم خاصة لإضافة وإدارة الصفحات.

## المميزات

### الموقع العام
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ✅ صفحات محسنة لمحركات البحث (SEO-Friendly)
- ✅ وسوم Meta Description و Keywords مخصصة لكل صفحة
- ✅ دعم Open Graph لمشاركة الصفحات على وسائل التواصل الاجتماعي
- ✅ بنية HTML دلالية (Semantic HTML)
- ✅ سرعة تحميل عالية

### لوحة التحكم
- ✅ نظام تسجيل دخول آمن
- ✅ إضافة صفحات جديدة بسهولة
- ✅ تعديل الصفحات الموجودة
- ✅ حذف الصفحات
- ✅ إحصائيات SEO للصفحات
- ✅ واجهة سهلة الاستخدام باللغة العربية

## التقنيات المستخدمة

- **Backend**: Node.js + Express.js
- **Database**: SQLite (باستخدام better-sqlite3)
- **Frontend**: EJS Templates + CSS3
- **Authentication**: Express Session

## التثبيت والتشغيل

### 1. تثبيت المكتبات
```bash
cd seo-website
npm install
```

### 2. تشغيل الخادم
```bash
npm start
```

أو:
```bash
node server.js
```

### 3. الوصول للموقع
- **الموقع الرئيسي**: http://localhost:3000
- **لوحة التحكم**: http://localhost:3000/admin/login

### بيانات تسجيل الدخول الافتراضية
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`

> ⚠️ **مهم**: قم بتغيير كلمة المرور في بيئة الإنتاج!

## كيفية إضافة صفحة جديدة

1. سجل الدخول إلى لوحة التحكم: `/admin/login`
2. انقر على "+ إضافة صفحة جديدة"
3. املأ الحقول التالية:
   - **عنوان الصفحة**: عنوان جذاب يحتوي على الكلمات المفتاحية
   - **الرابط (Slug)**: رابط URL بالإنجليزية (مثال: `seo-guide-2025`)
   - **محتوى الصفحة**: محتوى HTML كامل
   - **وصف الميتا**: وصف يظهر في نتائج البحث (150-160 حرف)
   - **الكلمات المفتاحية**: افصل بينها بفواصل
   - **Open Graph**: اختياري للمشاركة على وسائل التواصل
4. اضغط "إنشاء الصفحة"

## نصائح SEO المدمجة

لقد تم تضمين نصائح SEO مباشرة في لوحة التحكم:

- استخدم الكلمة المفتاحية الرئيسية في العنوان وأول فقرة
- قسّم المحتوى باستخدام عناوين فرعية (H2, H3)
- اجعل المحتوى طويلاً وشاملاً (1000+ كلمة)
- أضف روابط داخلية لصفحات أخرى ذات صلة
- استخدم الصور مع نصوص بديلة (Alt Text)
