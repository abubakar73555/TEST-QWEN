# موقع SEO على Cloudflare Workers

موقع إلكتروني متكامل يركز على تحسين محركات البحث (SEO) مع لوحة تحكم خاصة، مصمم للعمل على منصة Cloudflare Workers.

## المميزات

- ✅ **واجهة عربية كاملة** متجاوبة مع جميع الأجهزة
- ✅ **لوحة تحكم آمنة** لإضافة وتعديل وحذف الصفحات
- ✅ **تحسينات SEO متقدمة**:
  - وسوم Meta مخصصة لكل صفحة
  - دعم Open Graph و Twitter Cards
  - بيانات منظمة Schema.org (JSON-LD)
  - روابط Canonical
  - تحسين سرعة التحميل
- ✅ **نظام إدارة محتوى** سهل الاستخدام
- ✅ **تخزين KV** من Cloudflare لحفظ الصفحات
- ✅ **أمان عالي** مع نظام مصادقة بسيط

seo-worker-project/

## متطلبات التشغيل

1. حساب Cloudflare (مجاني)
2. Node.js مثبت على جهازك
3. Wrangler CLI (أداة سطر الأوامر لـ Cloudflare)

## خطوات التثبيت والنشر

### 1. تثبيت Wrangler CLI

```bash
npm install -g wrangler
```

### 2. تسجيل الدخول إلى Cloudflare

```bash
wrangler login
```

### 3. إنشاء KV Namespace

```bash
cd seo-worker-project
wrangler kv:namespace create "SEO_CONTENT"
```

سيظهر لك معرف (ID) خاص بـ KV Namespace. انسخه.

### 4. تحديث ملف الإعدادات

افتح ملف `wrangler.toml` واستبدل `YOUR_KV_NAMESPACE_ID` بالمعرف الذي نسخته:

```toml
[[kv_namespaces]]
binding = "SEO_CONTENT"
id = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### 5. تغيير كلمة المرور الافتراضية

في نفس الملف `wrangler.toml`، غيّر كلمة المرور:

```toml
[vars]
ADMIN_PASSWORD = "كلمة_مرور_قوية_هنا"
```

### 6. تجربة الموقع محلياً

```bash
npm install
npm run dev
```

افتح المتصفح على: `http://localhost:8787`

### 7. نشر الموقع على Cloudflare

```bash
npm run deploy
```

سيمنحك Wrangler رابطاً مباشراً لموقعك المنشور.

## استخدام لوحة التحكم

1. اذهب إلى: `https://your-site.workers.dev/admin/login`
2. أدخل كلمة المرور التي حددتها في `wrangler.toml`
3. يمكنك الآن:
   - إضافة صفحات جديدة مع عناوين SEO محسنة
   - كتابة وصف الميتا (Meta Description)
   - إضافة كلمات مفتاحية
   - عرض وحذف الصفحات المنشورة

## تحسينات SEO المضمنة

كل صفحة يتم إنشاؤها تحتوي تلقائياً على:

- ✅ عنوان الصفحة في وسم `<title>`
- ✅ وصف الميتا في وسم `<meta name="description">`
- ✅ الكلمات المفتاحية
- ✅ بيانات Open Graph لمشاركة أفضل على وسائل التواصل
- ✅ Twitter Card
- ✅ رابط Canonical
- ✅ بيانات منظمة Schema.org (Article أو WebSite)
- ✅ توجيهات للروبوتات (`index, follow`)

## نصائح لتحسين SEO

1. **العناوين**: استخدم عناوين واضحة وجذابة تحتوي على الكلمات المفتاحية
2. **وصف الميتا**: اجعله بين 150-160 حرفاً وشاملاً للمحتوى
3. **الكلمات المفتاحية**: اختر 3-5 كلمات مفتاحية ذات صلة
4. **المحتوى**: اكتب محتوى غني ومفيد (1000+ كلمة مثالي)
5. **التحديث المستمر**: حدّث المحتوى بانتظام

## الأمان

- كلمة المرور مخزنة في متغيرات البيئة
- لوحة التحكم محمية بنظام توكن
- جميع العمليات الحساسة تتطلب مصادقة
- يُنصح بتغيير كلمة المرور الافتراضية قبل النشر

## الدعم

إذا واجهت أي مشاكل:
1. تأكد من أن KV Namespace تم إنشاؤه بشكل صحيح
2. تحقق من أن المعرف في `wrangler.toml` صحيح
3. تأكد من تسجيل الدخول إلى Cloudflare عبر `wrangler login`
