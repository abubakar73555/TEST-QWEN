# موقع معدات السلامة

موقع إلكتروني متخصص في أدوات ومعدات السلامة

## نظرة عامة

هذا المشروع هو منصة إلكترونية لعرض وبيع معدات وأدوات السلامة المهنية باستخدام تقنيات الويب الحديثة.

## التقنيات المستخدمة

- **HTML5** - لهيكلة الصفحة
- **CSS3** - للتصميم والتنسيق
- **JavaScript (ES6+)** - للوظائف التفاعلية
- **Vite** - كأداة بناء وتطوير سريعة

## المميزات

- تصميم متجاوب يعمل على جميع الأجهزة
- واجهة مستخدم باللغة العربية
- عرض منتجات معدات السلامة
- تجربة مستخدم سلسة وسريعة

## متطلبات التشغيل

- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

## التثبيت

```bash
# تثبيت المكتبات المطلوبة
npm install
```

## التشغيل

### وضع التطوير

```bash
npm run dev
```

سيتم تشغيل الخادم المحلي عادة على `http://localhost:5173`

### البناء للإنتاج

```bash
npm run build
```

### معاينة النسخة المنتجة

```bash
npm run preview
```

## هيكل المشروع

```
├── index.html      # ملف HTML الرئيسي
├── main.js         # كود JavaScript الرئيسي
├── style.css       # ملفات التنسيق
├── package.json    # إعدادات المشروع والمكتبات
└── dist/           # مجلد البناء (يتم إنشاؤه تلقائياً)
```
